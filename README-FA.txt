ربات فقط‌خواندنی پایش انتقال‌های USDTI برای Ubuntu و systemd
قرارداد: TRpMNouAARgEA5KjtRjbb6f3n1FvmLoL4x

نصب: فایل فشرده را روی سرور بارگذاری و باز کنید، وارد پوشه شوید و اجرا کنید:
sudo bash install.sh

تنظیمات اختیاری:
sudo nano /etc/usdti-monitor.env
کلید TronGrid را در TRONGRID_API_KEY وارد کنید. دسترسی بدون کلید ممکن است محدود شود.
برای هشدار، توکن ربات تلگرام خود و شناسه چت مقصد خود را وارد کنید.
توکن را فقط روی سرور وارد کنید؛ ربات هیچ کلید خصوصی یا عبارت بازیابی نمی‌خواهد.
پس از تنظیم:
sudo systemctl restart usdti-monitor
sudo journalctl -u usdti-monitor -f
توقف:
sudo systemctl stop usdti-monitor

محدوده:
از پنج دقیقه قبل از اولین اجرا، رویدادهای Transfer تأییدشده را در SQLite ذخیره می‌کند.
اسکن دارای صفحه‌بندی و هم‌پوشانی پنج‌دقیقه‌ای است. تأخیر نمایه‌سازی بیش از این بازه ممکن است به جاافتادن رویداد منجر شود.
در خطای صفحه‌بندی، نقطه پیشرفت جلو نمی‌رود؛ رویدادهای تکراری با شناسه تراکنش و شماره رویداد حذف می‌شوند.
تلگرام صف پایدار و تلاش مجدد دارد؛ در قطع برنامه پس از ارسال و قبل از ثبت، هشدار ممکن است تکراری شود.
مقادیر به صورت واحد خام نمایش داده می‌شوند چون decimals قرارداد هنوز مستقلاً تأیید نشده است.
نام USDTI بر اساس اطلاعات کاربر است و کد تأیید اصالت، قیمت، لوگو یا امنیت قرارداد محسوب نمی‌شود.
این ربات تعداد کل هولدرها، حجم معاملات بازار یا قیمت را محاسبه نمی‌کند. انتقال لزوماً معامله نیست.
معامله، افزایش مصنوعی آمار و ثبت لوگو انجام نمی‌دهد.
دیتابیس به مرور رشد می‌کند؛ فضای دیسک و پشتیبان‌گیری را مدیریت کنید.
وضعیت Active تنها اجرای برنامه را نشان می‌دهد؛ Scan complete در لاگ نشانه موفقیت درخواست API است.

وابستگی: Python 3 استاندارد؛ بسته pip لازم نیست.
آزمایش‌ها: python3 -m unittest -v test_monitor.py
